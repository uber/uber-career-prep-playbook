# Phase 1 — Selection of Fellows

This phase covers the application process, marketing, and cohort interviews that result in a confirmed group of program fellows.

**Key Requirements:**

- [x] Finalize cohort logistics before the application launches.
- [x] Marketing efforts should reach the target audience.
- [x] Application review process should be thorough and unbiased.
- [x] Cohort interviews should be conducted efficiently and fairly.

---

## Cohort Planning

???+ abstract "Action"
    Confirm program logistics before the application launches.

???+ info "Guidance"
    - Follow the [Step by Step Planning Overview](../planning/index.md) and the Execution Checklist for Cohort Planning.
    - Ensure alignment with the [program timeline](../planning/step-03-create-timeline.md).

???+ question "Considerations"
    - Is there enough time to finalize logistics before the cohort launches?

---

## Marketing the Program & Application

???+ abstract "Action"
    The Core Program and Recruiting Teams collaborate on developing and implementing the application's marketing strategy.

???+ info "Guidance"
    - Link all marketing materials back to one main application.
    - Marketing materials should have virtual and digital options.
    - Marketing materials should include one contact point.
    - Marketing materials should have a clear call to action.

???+ question "Considerations"
    - What is the desired duration of the application period?
    - What timeframe is allocated for marketing the application?
    - Which organizations are targeted for partnerships?
    - What channels will be employed to promote the applications?
    - Are the marketing assets compatible across all intended platforms?
    - Where do you want to market the program?
    - Which schools or geographic locations will you market the program to? For example, if you want to reach students with different levels of access to opportunities, consider focusing on affordable colleges like state colleges.

---

## Application Review

???+ abstract "Action"
    Establish an application review procedure.

???+ info "Guidance"
    - Ensure the application process is approved by the Legal Team.
    - Establish clear application review guidelines.
    - Involve multiple reviewers to reduce bias.
    - List target schools/organizations for reviewers.
    - Use "knockout" questions for easy filtering.
    - Allocate sufficient time for application review.
    - Agree on the maximum number of interviewees.
    - Determine review time per application.
    - Require reviewers to justify recommendations.
    - Minimize application questions.
    - Maintain consistent question types.
    - Use filterable question types.
    - Clearly communicate the application process and timeline to candidates.

???+ question "Considerations"
    - What applicant tracking platform is used by your company?
    - Can you use the same platform for educational opportunities?
    - What's the number of projected applications and how will the review schedule be divided?
    - Are there specific recruiting targets or metrics that will impact the application review process?
    - Which critical questions will help obtain vital candidate information?
