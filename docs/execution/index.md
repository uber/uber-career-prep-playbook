# Program Execution Overview

The program is executed in three distinct phases:

```
Phase 1          Phase 2              Phase 3
─────────────    ───────────────────  ──────────────────────────
Selection of  →  Workshops        →   Post-Workshop
Fellows          (Core Learning)      (Internship Interviews
                                       + Outcomes)
```

| Phase | Focus | Key Output |
|-------|-------|-----------|
| [Phase 1 — Selection](phase-1-selection.md) | Application, review, and cohort interviews | Confirmed cohort of fellows |
| [Phase 2 — Workshops](phase-2-workshops.md) | 5 workshop sessions over ~8 months | Fellows complete 40 hrs of instruction |
| [Phase 3 — Outcomes](phase-3-outcomes.md) | Internship interviews, offers, retrospective | Placed interns + program learnings |
