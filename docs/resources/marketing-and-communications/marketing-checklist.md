# Marketing Check List

**Authors:** Julia Alberts  

## Key Copy

- Program summary

- Program mission/ vision

- Program “elevator pitch”

## Asset List 

- Global deck: contains all slides that can be linked to subsequent decks which enables effective and efficient updates to any cascading decks.

- Internal website: contains links to all program resources that can be used as a one-stop-shop for volunteers, key stakeholders, etc.

- Program logo

- Email template for any communications

<!-- -->

- Workshop deck templates

- Volunteer deck: contains details about volunteer opportunities, role description, responsibilities and how to sign-up.

- Training decks

## Application Launch Prep

- Landing page to drive all external applicants to learn about the program

- Application page

- QR code that directs to landing page and/or application page depending on where you want to send applicants to

## LinkedIn Application Launch 

- Images to be shared along with posts announcing:

  - Applications are open

  - Sharecard for Fellow accepted into cohort

  - Sharecard for Fellow completed program journey (now an alum)

  - Sharecard for Fellow accepted internship offer

- Post (image and messaging) of application opening

- Post (image and messaging) as a reminder that the application closes in 1 week

- Post (image and messaging) as a reminder that the application closes in 1 day

## External Partners Application Announcement 

- Email to external partners sharing that the application is now open

- Cascading comms to students that partners can share announcing the application is open

- Cascading comms to students that partners can share reminding students that applications close in 1 week

- Cascading comms to students that partners can share reminding students that applications close in 1 day
