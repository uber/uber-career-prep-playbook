# Welcome Deck

The Welcome Deck is included in the acceptance email to fellows as a way to confirm their place in the cohort. It includes an introduction slide template that each fellow completes with their name, pronouns, location, a fun fact and a photo, so the cohort can get to know each other.

Replace the `[YEAR]`, `[REGION]` and `[COMPANY]` placeholders with your program's details, and ask each fellow to make a copy of the intro slide.
