# Technical Resources

Everything the Technical Lead and technical volunteers need to run the technical side of the program: selecting the cohort, preparing fellows with practice assignments and workshops, and running mock interviews.

## Cohort selection

- [Cohort Selection Technical Interviews](cohort-selection.md): tips for interviewers and the question bank, with follow-ups and possible solutions for each question.

## Technical workshops

- [Technical Session Decks](technical-sessions/index.md): the four workshop decks, available to download as PowerPoint or PDF.

## Practice assignments

- [Practice Assignments](practice-assignments.md): five assignments that prepare fellows for the workshops, each with a solution guide for the volunteers who review them.
- [Practice Assignment Scorecards](practice-assignment-scorecards.md): the rubric volunteers use to review each assignment, with step-by-step instructions to recreate it as a Google Form.

## Mock interviews

- [Mock Interviews](mock-interviews.md): directions, interviewer tips and the question bank for each workshop, with solutions.
- [Peer Mock Interviews](peer-mock-interviews.md): the same for fellows running mock interviews with each other.
- [Mock Interview Scorecards](mock-interview-scorecards.md): the scorecard interviewers complete after each mock interview, with step-by-step instructions to recreate it as a Google Form.
