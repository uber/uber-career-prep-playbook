# Mock Interview Scorecards

After each mock interview, the interviewer submits a scorecard. There is one scorecard per mock interview round (1–4), and all four use the same questions. Only the list of interview questions differs. Submit the scorecard **immediately** after the interview, while the details are fresh.

This page contains everything you need to recreate the scorecards as Google Forms.

## Set up

Create **four** Google Forms, one per round, and give each one:

- **Title:** `UCP Open Source | Mock Interview N Feedback Form` (N = 1–4)
- **Description:** `This is the scorecard for mock interview N. Only ask questions from the mock interview N list in the question bank.`
- **Settings → Responses → Collect email addresses:** **Verified**, so that every scorecard is tied to the interviewer who wrote it

Then add the questions below, in order, to every form.

## Questions

| # | Question | Type | Required | Options |
|---|----------|------|----------|---------|
| 1 | Student's name (first & last) | Short answer | Yes | – |
| 2 | CodeSignal Link | Short answer | Yes | – |
| 3 | Copy Paste Code | Short answer | Yes | – |
| 4 | Which question did you ask? | Multiple choice | Yes | *Questions for this round (see below)* |
| 5 | Did you ask a second question? | Multiple choice | Yes | *Questions for this round (see below), plus* `Did not have time to ask a second question` |
| 6 | Overall Decision | Multiple choice | Yes | `Double Thumbs Up`<br>`Thumbs Up`<br>`Thumbs Down`<br>`Double Thumbs Down` |
| 7 | Behavioral (Soft Skills) Score | Linear scale | Yes | 0 to 3 |
| 8 | Technical (Hard Skills) Score | Linear scale | Yes | 0 to 3 |
| 9 | Pros | Paragraph | Yes | – |
| 10 | Cons | Paragraph | Yes | – |
| 11 | Conclusion | Paragraph | Yes | – |

## Questions for each round

Use these as the options for questions 4 and 5. Question 5 also gets the extra option shown above.

### Mock Interview 1

- First Element Occurring K Times in an Array
- Missing Elements in a Range
- Pangrams
- Isomorphic Strings

### Mock Interview 2

- Subarrays of Size K Containing Duplicates
- Max Stock Profit with Single Buy/Sell
- Number of Triplets with Zero Sum
- Max Meetings in a Room

### Mock Interview 3

- Reverse Linked List in Groups of k
- Max Height of Binary Tree
- Number of Nodes within k Distance of Root
- Median of a Sorted Linked List

### Mock Interview 4

- Count Paths Between Nodes
- Topping Possibilities
- Alien Dictionary
- Reorganize Array without Adjacent Duplicates

## Scoring

**Overall Decision** uses the same four-point scale on every UCP scorecard:

1. Double Thumbs Up
2. Thumbs Up
3. Thumbs Down
4. Double Thumbs Down

**Behavioral (Soft Skills)** and **Technical (Hard Skills)** scores are linear scales from 0 to 3.
