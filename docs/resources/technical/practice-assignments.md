# Practice Assignments

Fellows complete five practice assignments between the technical workshops. Each assignment is reviewed by a volunteer using a [scorecard](practice-assignment-scorecards.md), with the help of the solution guide.

| # | Topic | For fellows | For reviewers |
|---|-------|-------------|---------------|
| 0 | Arrays, Strings, & Hashing | [Assignment](assignments/assignment-0.md) | [Solution guide](assignments/assignment-0-solution.md) |
| 1 | Arrays & Strings | [Assignment](assignments/assignment-1.md) | [Solution guide](assignments/assignment-1-solution.md) |
| 2 | Linked Lists & Trees | [Assignment](assignments/assignment-2.md) | [Solution guide](assignments/assignment-2-solution.md) |
| 3 | Graphs & Data Structure Selection | [Assignment](assignments/assignment-3.md) | [Solution guide](assignments/assignment-3-solution.md) |
| 4 | Tries & Repeated Computation | [Assignment](assignments/assignment-4.md) | [Solution guide](assignments/assignment-4-solution.md) |

Assignments are shared with fellows after acceptance into the cohort. Solution guides are shared with the volunteers who review them.
