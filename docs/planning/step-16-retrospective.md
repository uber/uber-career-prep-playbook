# Step 16 — Program Retrospective

<span class="step-badge">Step 16 of 17</span>

???+ abstract "Action"
    Create a program retrospective and share with key stakeholders.

???+ info "Guidance"
    - Ensure all feedback is summarized into an easily digestible format.
    - Include actual program spend against the approved budget.
    - Host retrospective syncs with the Core Program Team and key volunteers to encourage open discussion and feedback.
    - Include a summary of positives / negatives / action items.
    - Differentiate actionable feedback from subjective opinions.

???+ question "Considerations"
    - How can feedback best narrate your program's impact?
