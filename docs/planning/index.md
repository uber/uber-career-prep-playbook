# Planning Your Program

This section breaks down the program's key components and provides step-by-step guidance on how to execute a successful Career Prep program.

Each step includes:

- **Action** — what you need to do
- **Guidance** — how to approach it
- **Considerations** — questions to ask yourself before moving on
