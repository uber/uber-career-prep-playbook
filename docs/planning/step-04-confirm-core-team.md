# Step 4 — Confirm Core Program Team

<span class="step-badge">Step 4 of 17</span>

???+ abstract "Action"
    Define your internal team's structure based on the Core Team roles and how many students your cohort will support.

???+ info "Guidance"
    - Carefully manage any role changes to ensure all responsibilities are covered for seamless operation.
    - Suggested Core Program Team roles:

    | Role | Responsibility |
    |------|---------------|
    | [Regional Program Lead](../roles/core-team.md#regional-program-lead) | Oversees program logistics, budget, communications, and speaker arrangements. |
    | [Technical Lead](../roles/core-team.md#technical-lead) | Oversees the program's technical aspects. Requires coding knowledge and comfort with technical presentations. |
    | [Mentors and Volunteers Lead](../roles/core-team.md#mentor-volunteer-lead) | Oversees volunteer coordination from start to finish. |
    | [Recruiting Support](../roles/core-team.md#recruiting-team) | Manages program launch marketing and supports interview and offer processes. |
    | [Workshop MC *(Optional)*](../roles/core-team.md#workshop-mc) | Leads workshops and keeps participants focused and engaged. MC role can be combined with the Regional Program Lead if additional headcount is not available. |

    !!! tip "Use alumni as MCs"
        Once you have program graduates, they make ideal MCs — they're familiar with the content and purpose of the program.

???+ question "Considerations"
    - Is there enough internal bandwidth for dedicated roles?
    - Does the cohort size demand dedicated roles?
    - Will roles be part-time or full-time positions?
    - Can the program be run by multiple teams, or does it require single-team alignment?
