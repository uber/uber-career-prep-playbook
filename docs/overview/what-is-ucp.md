# What is the Career Prep Program?

Uber Career Prep (UCP) is an unpaid, virtual fellowship program for undergraduate engineering students. It aims to provide transparency and guidance for starting a STEM career in tech.

The program focuses on removing barriers and supporting students' right to learn and succeed — because Uber believes everyone has potential, but not everyone has equal access to opportunity.

## Program Structure

Fellows attend **5 virtual workshops** led by Uber staff, scheduled every 7 weeks over approximately 8 months, completing **40 hours of instruction** in total.

Throughout the cohort, each fellow receives:

- **1:1 mentorship** from an Uber software engineer
- **4 mock interviews** with structured feedback
- **5 technical practice assignments** that build on each other in difficulty

## Workshop Topics

Workshops cover both technical and career-advancing subjects, including:

- Technical Mock Interviews
- 1:1 Mentorship
- Clear Code and Communication
- Negotiations
- Technical Competencies and Problem Solving
- LinkedIn and Resume Best Practices

## Internship Pipeline

At the end of the cohort, fellows who meet all program requirements are invited to interview for a **paid internship role** starting at the next internship cycle.

!!! tip "Key success factor"
    A key element and driver of success of this program is that it's run by the Engineering Team for future engineers.
